## 摘要

12K BTB、八表 TAGE、六宽 Decode/八宽 Rename、六条 ALU、三 AGU、80 项 Store Queue、2 MB Inclusive L2 与 96 项 Transaction Queue：V2 用更大的前端和缓存对抗 Server Code Footprint 与 Mesh Latency。

## 封面与分享文案

- 封面：Neoverse V2，Arm 的服务器大核走到哪了？
- 分享：V2 把 BTB 扩到 12K，L2 扩到 2 MB，并让 Prefetch 在模拟 SPEC 中贡献 5.3%。它与 Zen 4c 面积相近，却把晶体管花在了不同地方。
