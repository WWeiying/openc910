# C910 Store Queue 详解（ct_lsu_sq）

> RTL 源文件：`ct_lsu_sq.v`（3967 行）+ `ct_lsu_sq_entry.v`（1532 行）×12
>
> SQ 保存所有"已执行未提交"的 store：地址来自 pipe4、数据来自 pipe5，
> 退休后按序弹给 WMB。它同时是 store→load 前递的数据源——
> 乱序核访存性能的命门。

---

## 1. 表项生命周期

```
st_dc 创建(登记 PA/bytes_vld/iid/sdid)
  → sd_ex1 按 sdid 写入数据(64位) → 地址+数据齐 = 就绪
  → st_da 回写命中/way/dirty 预查信息
  → RTU 退休该 store → commit 位置 1（从推测态转提交态）
  → 按程序序弹出 → WMB（sq.v:3184 起 "pop entry"）
flush: 未 commit 的项清除；已 commit 的项保留（必须写出）
```

12 项的容量含义：最多 12 条 store 在"执行后~进 WMB 前"的窗口里。
store 密集代码（如 memset 类）SQ 满 → st_dc restart → pipe4 吞吐受限。

## 2. store→load 前递（sq.v:2876-3124 + entry 内比较）

### 2.1 三步协议

```
① ld_dc 广播: load 的 PA[39:4] + bytes_vld[15:0] + iid
   每个 SQ 项并行比较: 我比 load 老? 地址 16B 相同? 字节相交? 数据就绪?
② sq 汇总各项结果 → 三种结论之一:
   - 可前递: 给出唯一前递源 fwd_id（最年轻的重叠老 store——多项重叠时要"最近写者"）
   - 需 discard: 重叠但数据没到/部分覆盖/多项部分重叠拼不出来
   - 无关: 放行走 cache
③ ld_da 拍: case(ld_da_sq_fwd_id[11:0]) 独热选数（sq.v:3047-3076）
   sq_ld_da_fwd_data[63:0] 进 ld_da 的数据选择树（01_ld_pipeline.md 3.1）
```

### 2.2 为什么"部分覆盖"要 discard 而不是拼接

load 需要的字节可能一部分在 SQ、一部分在 cache（甚至跨两个 SQ 项）。
拼接逻辑 = 16 字节粒度的多源字节 mux,代价高、验证难。C910 选择 discard：
load 回 LSIQ 重发,等 store 写到 cache 后再来——用偶发的重发换数据通路的简单。
`LSU SQ Discard / SQ Data Discard`（perf 第 43/44 行）分别对应
"地址性放弃/数据未就绪放弃"两类，coremark 里各只有 1/10 次,说明编译器
排序已让这种场景很罕见。

### 2.3 restart 唤醒队列（sq.v:3125-3183）

被 discard 的 load 不是盲目重发：SQ 维护唤醒队列,等阻塞它的 store 数据
到位/弹出时精确唤醒对应 LSIQ 项——避免重发风暴。

## 3. 提交侧：弹出到 WMB（sq.v:3184-3685）

- 按创建序弹出（程序序）,每拍 1 项;
- `wmb ce`（create entry,sq.v:3519/3606）：弹出项打包
  地址/数据/bytes_vld/命中预查信息给 WMB;
- **sync.i/fence 特殊处理**（L3597 注释）：屏障指令弹出时清掉 pfu 状态;
- dcwp 比较（L3686）：弹出与 dcache 写口的 index 冲突规避。

## 4. 表项内的依赖比较（sq_entry.v）

每项自带一套与 ld_dc 的比较器（PA[39:4] 相等 + bytes_vld 相交 + iid 年龄
+ 数据 vld）,以及与 st_dc 新建项的 sdid/地址管理。1532 行 ×12 的面积大头
就是这些 CAM 式比较——**SQ 是 LSU 里最"贵"的结构**,12 项的规模是面积与
前递覆盖率的折中。

## 5. Verdi 观察建议

层次：`...x_ct_lsu_top.x_ct_lsu_sq`

| 信号 | 看什么 |
|------|--------|
| 各项 vld/commit 位 | 推测→提交转换;flush 时只有未 commit 项消失 |
| `ld_da_sq_fwd_id[11:0]` + `sq_ld_da_fwd_data` | 前递命中与数据 |
| discard 相关输出 | 前递失败回放 |
| 弹出口与 WMB 创建握手 | 提交流 |

跑一段 `str x, [addr]; ldr y, [addr]` 紧邻序列,前递必现;
把 store 数据改成依赖慢指令（除法结果）,即可看到 data discard。
